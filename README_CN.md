# ThingsBoard 物联网平台

## 概述
ThingsBoard 是一个开源的物联网平台，用于数据采集、处理、可视化和设备管理。它支持行业标准物联网协议，可用于云端和本地部署。

## 架构设计

### 整体架构
ThingsBoard采用分层架构设计，主要分为：
1. **传输层(Transport)**：处理设备连接和协议适配
2. **核心服务层(Core Services)**：业务逻辑处理
3. **规则引擎层(Rule Engine)**：数据流处理
4. **存储层(Storage)**：数据持久化
5. **Web UI层**：管理界面和可视化

### 模块详解

#### 1. Application模块
- **职责**：系统核心业务实现
- **关键组件**：
  - `controller`：REST API端点，处理HTTP请求
  - `service`：业务逻辑实现，如设备管理、租户管理等
  - `actors`：基于Actor模型实现异步处理
  - `config`：Spring配置和Bean定义
- **技术特点**：
  - 采用Spring Boot框架
  - 使用Spring Security实现认证授权
  - 基于JWT的令牌机制

#### 2. Common模块
- **职责**：提供公共组件和基础服务
- **关键组件**：
  - `data`：数据模型和DTO定义
  - `queue`：消息队列抽象层
  - `cache`：缓存实现(Redis/Caffeine)
  - `util`：工具类和辅助方法
- **技术特点**：
  - 提供统一的API接口
  - 支持多种实现的可插拔设计
  - 包含大量通用工具方法

#### 3. Transport模块
- **职责**：设备连接和协议处理
- **子模块**：
  - `mqtt`：MQTT协议实现(基于Netty)
  - `coap`：CoAP协议实现
  - `lwm2m`：LWM2M协议支持
  - `http`：HTTP接口
- **技术特点**：
  - 每种协议独立实现
  - 支持SSL/TLS加密
  - 可扩展的协议适配器

#### 4. Rule-Engine模块
- **职责**：处理设备数据流和业务规则
- **关键组件**：
  - `rule-engine-api`：规则定义接口
  - `rule-engine-components`：规则节点实现
- **工作流程**：
  1. 接收设备遥测数据
  2. 根据规则链处理数据
  3. 触发相应动作(告警、通知等)
- **技术特点**：
  - 基于规则链的可视化配置
  - 支持多种过滤和转换操作
  - 可扩展的规则节点

#### 5. UI模块(ui-ngx)
- **职责**：提供管理界面和数据可视化
- **关键特性**：
  - 基于Angular框架
  - 响应式设计
  - 丰富的仪表盘组件
  - 规则链可视化编辑器

### 数据流分析
1. **设备接入流程**：
   设备 → Transport层 → 核心服务 → 规则引擎 → 存储

2. **数据查询流程**：
   Web UI → REST API → 核心服务 → 存储 → 返回数据

3. **告警处理流程**：
   规则引擎检测 → 创建告警 → 通知服务 → 用户
